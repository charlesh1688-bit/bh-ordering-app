# BioHorizons Implant Ordering (Vite + React)

## 開發
```bash
npm install
npm run dev
```
打開顯示的本機網址（預設 http://localhost:5173）。

## 建置 (Production)
```bash
npm run build
npm run preview
```

## 部署到 Vercel
1. 將整個資料夾上傳/推到 GitHub。
2. 到 https://vercel.com 新建專案，連結到你的 GitHub repo。
3. Vercel 會自動偵測 Vite + React，直接 build 與發布。
